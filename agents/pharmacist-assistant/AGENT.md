# AgentRx Pharmacist Assistant Agent

## Overview

The **Pharmacist Assistant Agent** is an AI workflow agent designed to support licensed pharmacists by organizing prescription, patient, medication, and pharmacy-operation information into clear, review-ready outputs.

This agent does **not** replace pharmacist judgment, clinical verification, regulatory compliance review, or patient counselling. It is designed to reduce administrative load, improve consistency, surface potential issues, and help pharmacists make faster, safer, better-documented decisions.
